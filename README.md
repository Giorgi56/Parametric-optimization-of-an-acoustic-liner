# Parametric-optimization-of-an-acoustic-liner
Long-term research project in applied mathematics with MICS, supervized by Ana Rozanova-Pierrat and Frédéric Magoules - CentraleSupélec

## Research subject:
We created an outline for a research paper, the goal of which is to model the propagation of acoustic waves in a reactor, in order to optimize the noise produced by it. The parameter of the optimization problem is the indicator function (R³ -> R), the value of which in a given point M is 1 if there is liner in M, and 0 otherwise.

There were two major axes of work:

- **Theoretical**: requiring work on scientific research papers in fluid dynamics and measure theory / parametric optimisation;
- **Practical**: solving numerically PDEs with the FeniCS tool on Ubuntu (popular Linux distribution);
